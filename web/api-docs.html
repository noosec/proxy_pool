ProxyPool API 文档

接口 · 参数 · 调用样例 返回面板
基础地址：http://192.168.0.9:5010　（所有接口均为 GET，返回 JSON）
/get /pop /delete /all /count /stats /dashboard /
GET/get随机返回一个可用代理
参数类型必填说明
typestring可选协议过滤：http / https / socks4 / socks5
regionstring可选地域过滤：国家码（如 CN、US、HK），大小写不敏感
checkstring可选1 表示现场拨测通过才返回（最多试 6 个，失败即剔除）
type=https 表示「http 协议且支持 https 的代理」——返回结果的 proto 字段是 http（代理协议不存在 https 这个值），靠 https: true 标志表示支持 https，且不含 socks5/socks4（即使其 https 字段为 true）。

调用样例

# 随机获取一个 http 代理
curl "http://192.168.0.9:5010/get/?type=http"

# 获取一个 CN 地域的 https 代理
curl "http://192.168.0.9:5010/get/?type=https&region=CN"

# 现场拨测通过才返回（socks5）
curl "http://192.168.0.9:5010/get/?type=socks5&check=1"

响应样例

{
  "proxy": "61.155.100.100:3128",
  "https": true,
  "proto": "http",
  "fail_count": 0,
  "region": "CN",
  "anonymous": "",
  "source": "monosans",
  "check_count": 3,
  "last_status": true,
  "last_time": "2026-09-24 12:00:00"
}
无可用代理时返回 {"code": 0, "src": "no proxy"}；拨测无可用时返回 {"code": 0, "src": "no usable proxy after live check", "tried": 6}。
GET/pop获取并删除一个代理
参数类型必填说明
typestring可选协议过滤：http / https / socks4 / socks5

调用样例

curl "http://192.168.0.9:5010/pop/"

响应样例

{
  "proxy": "61.155.100.100:3128",
  "https": true,
  "proto": "http",
  ...
}
GET/delete删除指定代理
参数类型必填说明
proxystring必填代理地址，形如 127.0.0.1:8080

调用样例

curl "http://192.168.0.9:5010/delete/?proxy=127.0.0.1:8080"

响应样例

{"code": 0, "src": 1}
末尾斜杠为标准写法（Flask strict_slashes 下直接命中）；省略斜杠会 308 重定向到带斜杠地址，功能等价。
GET/all返回池中全部代理（数组）
参数类型必填说明
typestring可选协议过滤：http / https / socks4 / socks5

调用样例

curl "http://192.168.0.9:5010/all/"

响应样例

[
  {"proxy": "61.155.100.100:3128", "https": true, "proto": "http", ...},
  {"proxy": "203.0.113.5:1080", "https": false, "proto": "socks5", ...}
]
GET/count代理数量统计

调用样例

curl "http://192.168.0.9:5010/count/"

响应样例

{
  "http_type": {"http": 203, "https": 85},
  "source": {"monosans": 150, "proxifly": 80, ...},
  "count": 288
}
GET/stats聚合统计（面板数据源）
字段说明
total代理总数
https支持 https 的代理数
by_proto按协议分布（http/socks4/socks5/multi）
by_source按来源分布（降序数组 [名称, 数量]）
by_region按地域分布（降序数组 [国家码, 数量]，未知归「未知」）
recent最近代理（前 20，完整字段）
fetch_log采集日志尾部 60 行
check_log校验日志尾部 60 行

调用样例

curl "http://192.168.0.9:5010/stats"

响应样例

{
  "total": 288,
  "https": 85,
  "by_proto": {"http": 200, "socks5": 60, "socks4": 28},
  "by_source": [["monosans", 150], ["proxifly", 80]],
  "by_region": [["未知", 786], ["CN", 150], ["US", 40]],
  "recent": [ ... ],
  "fetch_log": ["..."],
  "check_log": ["..."]
}
GET/dashboard图形化代理面板（HTML）

调用样例

# 浏览器直接访问
http://192.168.0.9:5010/dashboard
GET/接口索引（JSON）

响应样例
